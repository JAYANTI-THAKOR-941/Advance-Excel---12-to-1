# Advanced Excel practical course

Use Microsoft Excel with the fictional dataset sales.csv. Import through Data > From Text/CSV and confirm dates and numeric fields. Convert the imported data to an Excel Table named Sales.

| Module | Practice |
|---|---|
| 1 | Tables, sorting, filtering, data validation |
| 2 | SUM, AVERAGE, IF and absolute references |
| 3 | SUMIFS, COUNTIFS and lookup functions |
| 4 | Text cleaning and date functions |
| 5 | Pivot tables and slicers |
| 6 | Charts and dashboard design |
| 7 | Power Query import and transformations |
| 8 | Capstone sales reporting |

See [formula workbook guide](formulas.md), [dashboard assignment](dashboard.md) and [fictional data](sales.csv). Formula examples use English function names and comma separators; availability varies by Excel version.
