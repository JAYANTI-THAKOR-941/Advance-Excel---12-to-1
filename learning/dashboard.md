# Sales dashboard capstone

1. Import sales.csv and create the Sales table.
2. Calculate revenue, cost, profit and margin.
3. Build a PivotTable: Region in Rows, Product in Columns, Revenue in Values (Sum).
4. Create a second PivotTable grouped by month using the Date field.
5. Add region and product slicers where supported.
6. Build column charts for regional revenue and monthly revenue, plus KPI cells for total revenue, profit and weighted margin.
7. Use Power Query to import the CSV, set date and numeric types, and load the result to a table. Inspect rather than blindly delete errors.
8. Refresh after adding a fictional transaction. Reconcile dashboard totals against the source table.

## Evaluation rubric (20 marks)
Data preparation 4; calculated fields 4; pivot tables 4; visualization and clarity 4; validation and explanation 4.

The CSV is fictional and does not contain customer records. This assignment is a workbook-building guide, not a prebuilt Excel dashboard.
