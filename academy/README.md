# Advanced Excel practice academy

Supplementary classroom course. Use Microsoft Excel and a copy of the fictional sales dataset. English formula names and comma separators are used; some Excel versions and locales differ.

| Module | Topic | Practical |
|---|---|---|
| 1 | Excel tables and formatting | Convert sales data into a table |
| 2 | Relative and absolute references | Calculate line revenue |
| 3 | SUM, AVERAGE, MIN, MAX | Revenue summary |
| 4 | IF and IFERROR | Performance classification |
| 5 | COUNTIF and SUMIFS | Regional analysis |
| 6 | XLOOKUP and VLOOKUP | Product categories |
| 7 | Text and date functions | Extract month |
| 8 | Data validation | Validate discount values |
| 9 | Conditional formatting | Highlight high revenue |
| 10 | PivotTables and slicers | Regional report |
| 11 | Charts and dashboards | Sales visualization |
| 12 | Power Query | Import and transform data |

Resources: [Sales dataset](sales.csv), [Product lookup](products.csv), [Formula handbook](FORMULAS.md), [Assignments and answers](ASSIGNMENTS.md).
